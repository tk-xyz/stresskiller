# Pofuduk Dövme Odası

Tarayıcıda oynanan, fizik tabanlı bir peluş oyuncak dövme oyunu. Kurulum gerekmez; `index.html` dosyasını açmak yeter.

**Oyna:** https://tk-xyz.github.io/stresskiller/

## Nasıl oynanır

- **Sol tık / dokun:** vur. Basılı tut: yakala ve fırlat.
- **Sağ tık:** iğnele (telefonda İğne aleti).
- **Aletler (1-6):** El, İğne, Çekiç, Testere, Çakmak, Benzin.
- **Yüz:** Peluşa kendi fotoğrafını yüz olarak ekle; fotoğraf yalnızca senin tarayıcında kalır.

Sesler tarayıcıda üretilir; harici dosya kullanılmaz.
